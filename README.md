# 윈도우탭노트 (WindowsTabNote)

최신 Windows 11 메모장의 화면과 조작 방식을 재현한 macOS용 네이티브 텍스트 편집기입니다.

## 기능

- 여러 문서를 탭으로 동시에 열기
- 저장 전에는 첫 문장을 탭 제목으로 사용하고, 저장 후에는 파일명 우선
- 긴 탭 제목의 끝쪽 말줄임표 처리와 다중 탭 자동 폭 조절
- 작은 창에서는 서식 도구를 자동으로 접는 반응형 레이아웃
- Windows 11 스타일 제목줄, 창 버튼, 메뉴 및 상태표시줄
- 기본 다크 모드와 눈부심을 낮춘 소프트 라이트 모드
- `.txt`를 포함한 일반 텍스트/소스 파일 열기
- 큰 파일을 열 때도 창이 멈추지 않는 백그라운드 로딩
- 저장 및 다른 이름으로 저장
- 수정된 탭 표시와 닫기 전 저장 확인
- 찾기/바꾸기, 줄로 이동
- 제목, 목록, 굵게, 기울임, 취소선, 링크, 이미지, 표 Markdown 도구
- 자동 줄 바꿈
- 글자 확대/축소
- 현재 행/열, 줄 바꿈 방식, 인코딩 표시
- 입력 중에는 현재 탭과 상태표시줄만 갱신하는 경량 처리

## 단축키

| 기능 | 단축키 |
| --- | --- |
| 새 탭 | `⌘T` 또는 `⌘N` |
| 열기 | `⌘O` |
| 저장 | `⌘S` |
| 다른 이름으로 저장 | `⇧⌘S` |
| 현재 탭 닫기 | `⌘W` 또는 `Ctrl+W` |
| 찾기 | `⌘F` |
| 찾기/바꾸기 | `⌥⌘F` |
| 줄로 이동 | `⌘L` |
| 확대/축소 | `⌘+` / `⌘-` |

## 빌드

```sh
./build.sh
```

빌드 결과는 `dist/윈도우탭노트.app`과 `dist/WindowsTabNote-macOS.zip`에 생성됩니다.
