# 윈도우탭노트 (WindowsTabNote)

최신 Windows 11 메모장의 화면과 조작 방식을 재현한 macOS용 네이티브 텍스트 편집기입니다.

## 기능

- 여러 문서를 탭으로 동시에 열기
- 다른 탭은 첫 클릭으로 전환하고, 선택된 탭을 다시 클릭하면 이름 편집 (전체 선택, Enter/바깥 클릭으로 확정, Esc로 취소)
- 이름 편집은 탭 아래의 넓은 팝업에서 진행해 좁은 탭에서도 긴 이름을 편하게 수정 (변경·취소 버튼 제공)
- 직접 지정한 탭 이름은 재실행 후에도 유지 (연결된 파일명과 본문은 그대로 유지)
- 직접 지정한 탭 이름이 없으면 저장 전에는 첫 문장, 저장 후에는 파일명을 제목으로 사용
- 긴 탭 제목의 끝쪽 말줄임표 처리와 다중 탭 자동 폭 조절
- 탭 개수와 관계없이 창 축소 가능, 넘치는 탭은 가로 스크롤·모든 탭 메뉴로 탐색
- 탭을 좌우로 드래그해 순서 변경, 가장자리에서 자동 스크롤
- 가운데 클릭으로 탭 닫기, 다른 탭을 닫아도 현재 메모 유지
- 작은 창에서는 서식 도구를 자동으로 접는 반응형 레이아웃
- Windows 11 스타일 제목줄, 창 버튼, 메뉴 및 상태표시줄
- 기본 다크 모드와 눈부심을 낮춘 소프트 라이트 모드
- `.txt`를 포함한 일반 텍스트/소스 파일 열기
- 큰 파일을 열 때도 창이 멈추지 않는 백그라운드 로딩
- 저장 및 다른 이름으로 저장
- 수정된 탭 표시와 닫기 전 저장 확인
- 창을 닫거나 앱을 종료해도 탭 순서와 저장하지 않은 내용을 다음 실행 때 자동 복원
- 찾기/바꾸기, 줄로 이동
- 제목, 목록, 굵게, 기울임, 취소선, 링크, 이미지, 표 Markdown 도구
- 자동 줄 바꿈
- 글자 확대/축소
- 현재 행/열, 줄 바꿈 방식, 인코딩 표시
- 입력 중에는 현재 탭과 상태표시줄만 갱신하는 경량 처리

## 단축키

| 기능 | 단축키 |
| --- | --- |
| 새 탭 | `⌘T` 또는 `⌘N` |
| 열기 | `⌘O` |
| 저장 | `⌘S` |
| 다른 이름으로 저장 | `⇧⌘S` |
| 현재 탭 닫기 | `⌘W` 또는 `Ctrl+W` |
| 다음 / 이전 탭 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| 찾기 | `⌘F` |
| 찾기/바꾸기 | `⌥⌘F` |
| 줄로 이동 | `⌘L` |
| 확대/축소 | `⌘+` / `⌘-` |
| 화면에 표시된 줄의 왼쪽/오른쪽 끝 | `Home` / `End` |
| 문서 맨 처음/끝 | `Ctrl+Home` / `Ctrl+End` |
| 위 이동 위치까지 선택 | 위 단축키에 `Shift` 추가 |

Home/End 키가 없는 Mac 키보드는 `Fn+←` / `Fn+→`를 사용할 수 있습니다.

## 빌드

```sh
./build.sh
```

빌드 결과는 `dist/윈도우탭노트.app`과 `dist/WindowsTabNote-macOS.zip`에 생성됩니다.

키 이동·선택, 탭 이름 편집, 다중 탭 창 축소·순서 변경, 세션 호환성 검증은 `zsh Tests/run.sh`로 실행합니다.
